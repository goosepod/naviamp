# Signal N variations

1. **Precision N** — solid, seamless geometry with subtle audio level marks.
2. **Stroke N** — the simplest and most open interpretation.
3. **Ribbon N** — a dimensional treatment with a lighter inner signal.
4. **Negative Signal N** — reverses the mark out of a bright blue field.
5. **Spectrum N** — divides the exact N geometry into audio-spectrum bands.

Every diagonal now terminates directly on its upright, so the monogram reads as a deliberately constructed N at both large and launcher sizes.
