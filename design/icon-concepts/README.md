# Naviamp v2 icon concepts

Five original, scalable SVG directions for replacing the current Naviamp mark. Each uses a 1024 by 1024 app-icon canvas, keeps Naviamp's blue identity, contains no font dependency, and avoids the current Navidrome-like combination of broadcast arcs, a center disc, and a play triangle.

1. **Signal N** — the clearest Naviamp monogram; audio levels flank a signal-built letter N.
2. **Audio Orbit** — a more abstract, energetic identity centered on music discovery and motion.
3. **Wave Bridge** — a bold continuous waveform suited to playback and audio-quality positioning.
4. **Album Stack** — emphasizes the music library and album-art experience.
5. **Amp Dial** — emphasizes Naviamp as a serious player with an amplifier-inspired control motif.

The selected direction should receive small-size legibility checks, monochrome/status-icon adaptations, platform safe-area tuning, and final Android adaptive-icon, iOS, macOS, Windows, and Linux exports before replacing production assets.

Expanded studies are available in `signal-n-variations/` and `waveform-na-variations/`. The Signal N studies correct the original diagonal alignment; the Waveform NA studies add a final descent so the signal subtly suggests the initials “NA.”
