# Naviamp 2.1 Release Notes

Naviamp 2.1 adds library-aware genre exploration, more useful Navidrome smart-playlist tools, and
finer Now Playing metadata controls. The concise user-facing change list is in
[`CHANGELOG.md`](../CHANGELOG.md#v210).

## Genre discovery

Genre Mix now projects the genre tags reported by the active music server onto a bundled
MusicBrainz hierarchy. The browser contains only branches relevant to the current library. Expanding
a parent reveals its available subgenres; selecting that parent adds every provider genre beneath
it to the mix while preserving the exact names expected by the server.

The hierarchy is deliberately conservative. Unmatched tags remain available in an Other Genres
section. If the library is too small, mapping coverage is too low, or the hierarchy would not reduce
the initial choice set enough, Naviamp presents the complete flat genre list instead.

The bundled snapshot contains MusicBrainz core genre entities, aliases, and relationships under
CC0. It is installed locally and does not introduce a runtime MusicBrainz service dependency. See
the [dataset research](genre-ontology-dataset-research.md),
[import audit](genre-ontology-import-audit.md), and
[third-party notices](../THIRD_PARTY_NOTICES.md) for provenance and scope.

## Smart playlists

Navidrome's smart-playlist editor can search the full ontology and resolve a selected canonical
genre to the matching genre names used by the current library. Supported filters are previewed
against the locally synced track index after a short debounce, showing matching and post-limit
counts plus representative tracks before the playlist is saved.

Rules that require data unavailable in the local index are not guessed. Naviamp explains that the
preview is unavailable while still allowing Navidrome to evaluate the saved playlist normally.
Smart-playlist creation and editing remain provider-specific capabilities.

## Now Playing

The interface can show either an album's original release year or the year of the specific edition.
Original-year metadata is retained through library indexing, caches, downloads, queues, and restored
sessions. Album artwork remains the default in Now Playing, with a new setting to prefer
track-specific artwork when the provider supplies it.

## Upgrading and compatibility

- Install `v2.1.0` over an existing `v2.0.1` installation; no reset is required.
- The shared database migration installs the genre ontology and preserves existing application data.
- Refreshing the library also refreshes its provider genre inventory. Opening Genre Mix can populate
  an empty inventory on demand.
- Android, macOS, Windows, and Linux remain the supported release targets. The iOS arm64 IPA remains
  an unsigned preview for users who provide their own signing.
- Linux secure credentials still require Secret Service and `secret-tool`. Windows and macOS
  packages are not publisher-signed and may display operating-system warnings.
