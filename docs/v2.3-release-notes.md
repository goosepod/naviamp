# Naviamp 2.3 Release Notes

Naviamp 2.3 makes queue insertion understand playback-profile groups, adds an optional shared stereo
downmix for multichannel music, and keeps waveform work bounded and responsive for long remote
tracks. The concise user-facing change list is in [`CHANGELOG.md`](../CHANGELOG.md#v230).

## Group-aware Play Next

Play Next now treats a currently playing album or playlist group as a deliberate sequence. The
requested tracks are inserted after that group's boundary instead of splitting its remaining tracks
or accidentally extending its playback profile to unrelated music.

The separate Play Next Track action remains the explicit interruption control. It places the
requested track directly after the current track, then resumes the remainder of the original group.
Both behaviors are Core-owned, preserve request order, survive session restoration, and protect the
scheduled insertion from upcoming-track shuffle.

## Optional stereo downmix

Playback > Audio Output includes a Stereo Downmix switch that is off by default. When enabled,
Naviamp creates a stereo mixer and applies the same Core-owned matrix on Android, macOS, Windows,
Linux, and iOS. Stereo sources pass through unchanged; multichannel sources use explicit matrices
for 3.0, quad, 5.0, 5.1, 6.1, and 7.1 layouts, with a conservative fallback for unknown layouts.

Front channels remain side-specific, center and paired surround or rear channels enter at -3 dB,
and LFE or a single back-center channel enters at -6 dB. Each output row is normalized before
ReplayGain, equalization, and user volume so fully correlated full-scale channels cannot clip while
being summed.

Stats for Nerds reports the source layout, active output channels, saved preference, and effective
channel processing. Changing the preference clears the prepared-next stream; restart the current
track if the change should apply immediately.

## Long-track waveform reliability

Remote waveform analysis now consumes HTTP response bodies as a live stream and asks each native
BASS adapter for a bounded sequential decoder. It no longer needs to retain an entire large audio
file merely to analyze it from beginning to end.

When a saved session restores a track, transport and metadata become available first. Waveform,
lyrics, and embedded-tag work resumes through the existing cancellable background sidecar job so a
long track cannot hold up playback restoration. Android and Desktop also initialize their native
BASS analysis boundary before that background work, allowing a paused track to rebuild its waveform
after a cold launch without requiring playback to start first.

## Additional fixes

- The saved Stereo Downmix preference is applied to the active playback engine as well as shown in
  Settings and Stats for Nerds.
- Opening a connection editor from Settings keeps the complete editor visible and usable.

## Upgrading and compatibility

- Install `v2.3.0` over an existing `v2.2.0` installation; no reset is required.
- This release adds no database migration. The new serialized Stereo Downmix preference defaults to
  off when absent, preserving the prior output behavior for existing installations.
- Native multichannel output is still unverified and is not claimed. Stereo downmix is the tested
  option for headphones and two-channel speakers.
- Android, macOS, Windows, and Linux remain the supported release targets. The iOS arm64 IPA remains
  an unsigned preview for users who provide their own signing.
- Windows and macOS packages are not publisher-signed and may display operating-system warnings.
