# Service branding

These bundled assets identify services in Naviamp's shared account picker and saved connections.
The project owner confirmed permission with the original service creators for use in apps connecting
to their services (issue #271). The owner subsequently supplied the Aurral asset in issue #359.
Original colors and aspect ratios are retained; icons accompany text labels. Original assets were
retrieved 2026-10-11; later additions are dated below. Service names and trademarks belong to their
respective owners.

| Resource | Source |
| --- | --- |
| `service_aurral.png` | Owner-supplied https://github.com/lklynet/aurral/blob/main/docs/public/favicon.svg, retrieved 2026-10-27. The original is retained as `aurral-favicon.svg`; rasterized proportionally at width 512 with `rsvg-convert`, retaining its original lime color and transparency. |
| `service_bandcamp.png` | Aqua circle button from https://bandcamp.com/buttons; https://s4.bcbits.com/vite/corp-pages/client/v1/en/assets/bandcamp-button-circle-aqua-512-DR-rk-YT.png |
| `service_opensubsonic.png` | OpenSubsonic organization avatar supplied by the owner: https://avatars.githubusercontent.com/u/125784570?s=200&v=4 |
| `service_navidrome.png` | https://github.com/navidrome/navidrome/blob/master/resources/logo-192x192.png |
| `service_jellyfin.png` | Official raster counterpart to the supplied SVG branding: https://github.com/jellyfin/jellyfin-ux/blob/master/branding/web/icon-transparent.png |
