# Service branding

These bundled assets identify services in Naviamp's shared account picker and saved connections.
The project owner confirmed permission with the service creators for use in apps connecting to their
services (issue #271). Original colors and aspect ratios are retained; icons accompany text labels.
Retrieved 2026-10-11. Service names and trademarks belong to their respective owners.
