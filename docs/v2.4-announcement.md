# Naviamp 2.4.0: library browsing, playlists, and a new player workspace

Draft for the GitHub **Announcements** category. Publish only after the release ships.

Naviamp 2.4.0 brings faster repeat visits to large album libraries, clearer artist discographies,
playlist membership editing, and a player that can stay beside your browsing screens.

- Browse Artists, Albums, and Songs with independent search and alphabetical navigation.
- Manage a track's playlists in one place, including creating a playlist from the membership editor.
- Put Favorite Artists on Home and arrange Home sections directly in Settings.
- Switch between a docked Split player and Full player in wide windows; narrow windows keep the
  stacked player.
- Customize Aurora's color count, angle, and tone, with smoother waveform progress.

Fixes improve playlist reconciliation, OpenSubsonic compatibility, artwork continuity, Windows
equalization, and reading comfort across window sizes.

Existing v2.3.1 installations are intended to upgrade without resetting app data. The release adds
shared database tables for favorite-artist activity, artist credits, and album catalog snapshots.
The first album index may take time; later visits reuse the saved metadata. New portable settings
participate in export/import and sync.

The iOS download remains an unsigned preview requiring your own signing. Windows and macOS
packages remain unsigned.
