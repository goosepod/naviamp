## Native boundary audit

The radio implementation changes `platforms/ios/src/iosMain/kotlin/app/naviamp/ios/playback/IosBassPlayback.kt`
only to call the BASS `BASS_ChannelGetTags` C API and translate its native buffers/pointers into
shared metadata. `native/bass-jni/src/naviamp_bass_jni.cpp` performs the same native ABI operation
for Android/Desktop. Metadata interpretation, filtering, redaction, state and UI are common.
No Android/Desktop Kotlin production files change. Release preparation changes the Xcode project
only for packaging version/build defaults.
