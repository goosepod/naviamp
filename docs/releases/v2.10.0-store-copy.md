## What's new — Apple and Microsoft

Naviamp 2.10.0 adds dedicated Aurral connections with artist discovery, sample
playback, library requests and monitoring when your account permits it. Samples
preserve your main queue and playback position.

Connect to certificate-protected music servers with imported client identities and
private server authorities. Browse artist playlists, customize artist pages, edit
smart playlists with clearer summaries and named references, and search your library
without losing your browse position.

This update also improves playback recovery, accessible player controls, Windows
menus and credentials, and storage totals. Choose any of 17 bundled interface
languages; untranslated text falls back to English.

Upgrade other devices to 2.10.0 or later before syncing newly selectable language
choices. Import certificate files separately on each device. Android TV recovery
and position findings, Android animation performance and additional visible Mac
testing remain follow-ups described in the release notes.

## Google Play release notes — under 500 characters

Discover artists, play samples and request music through Aurral. Connect to certificate-protected servers. Enjoy improved artist pages, smart-playlist editing, Library search, playback recovery and accessible controls. Choose from 17 interface languages, with English fallback for missing translations. Update other devices to 2.10.0 before syncing new language choices. Android TV recovery/position issues and animation performance remain follow-ups.

## Reviewer / beta testing focus

- Use the existing dedicated review server and private account fields. Verify fresh
  connection, saved-login relaunch, browsing and playback on the selected build.
- Aurral features require a compatible server and account permissions; ordinary
  Navidrome/OpenSubsonic/Jellyfin login does not expose Aurral-only actions.
- Exercise pause, seek, next track, queue continuity, downloads/offline playback,
  library search and keyboard/remote focus. Check export/import and language switching.
- On Mac, verify sandboxed typing/paste, file selection, native library loading,
  saved credentials and background audio through the actual store package.
- On Windows MSIX, verify the fixed fresh-profile credential creation and relaunch,
  plus coexistence/upgrade and data preservation; the standalone check is separate.
- Retain the accepted limitations. Do not tell reviewers that deferred TV recovery
  or Android performance findings are fixed, or that unperformed Apple testing passed.
