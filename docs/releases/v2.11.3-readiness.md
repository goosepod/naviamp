## Candidate verification

The release metadata check reported v2.11.3, Windows installer version 2.11.64, and Linux
package version 2.11.3. Release-tag and announcement validation and all eight release workflow
tests passed locally. The packaging guard accepted official Temurin 21.0.13.1+2 on Apple Silicon
and rejected the local 21.0.13.0.3 JDK. A jlink image created with the patched JDK reported
`JAVA_VERSION="21.0.13.1"` in its metadata. Both target release task graphs included the
JDK and bundled-runtime checks. The Discord announcement dry run produced the expected title.
All five shared About and changelog tests passed on the combined candidate. The rendered
changelog displayed both fixes in release order.

Both native x64 `:apps:desktop:stageReleaseArtifacts` builds completed with the pinned Corretto JDK.
The release files and their SHA-256 manifest are in the worktree under `build/hotfix-v2.11.3`.
The full release CI matrix, the signed Flatpak refresh, and channel publication are pending.
Link the implementation PR in the curated GitHub notes before publication.

## Sunshine taskbar verification

The installed, Store-signed v2.11.2 package used a transparent manifest background and three base
logo PNGs. It had no target-size variants or package resource index. The three logo hashes matched
the files used for the Sunshine baseline.

Sunshine ran both test MSIX packages and the extracted public v2.11.2 MSI in the foreground at the
same display settings. Both MSIX packages used the hash-verified v2.11.2 app payload with
identical test-only launcher settings and separate package identities. The launches used
Adoptium's temporary JVM mitigation and Naviamp's development data profile. The baseline reproduced the blue rectangle. The corrected package
removed it and matched the standalone MSI icon. The tested generator produced 45 transparent PNG
variants across 15 target sizes. MakePri indexed both light and dark unplated variants, and MakeAppx
semantic validation passed with the final artwork-only index.

The rebuilt ZIP and isolated MSIX test installation each opened a foreground Naviamp window on
Sunshine. Both processes loaded the verified Corretto JVM DLL, and the Store icon matched the
standalone icon. The test MSIX used a separate package identity and a development data profile.
It used the patched JVM without the Base64 workaround. The test MSIX and scheduled task were
removed after the run.
