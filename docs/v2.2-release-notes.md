# Naviamp 2.2 Release Notes

Naviamp 2.2 adds per-album and per-playlist playback profiles, carries them through explicit queue
groups, and makes waveform seeking more accurate in demanding transition states. The concise
user-facing change list is in [`CHANGELOG.md`](../CHANGELOG.md#v220).

## Continuous playback profiles

Album and saved-playlist detail screens now include a Playback Profile editor. Each profile can
override the global transition mode with gapless playback, a configurable crossfade, or a deliberate
pause. ReplayGain can independently inherit the global setting or select off, track, or album gain.
Returning both fields to inherit clears the saved profile.

Profiles are source-scoped local preferences. They remain associated with the album or playlist on
the selected music source and do not modify provider metadata or synchronize back to the server.

## Queue groups and precedence

Playing an album in order creates a queue group, and its saved profile is applied to tracks and
transitions inside that group. Adding a profiled album to the queue also carries the group and
profile. Starting a configured saved playlist in order uses the playlist profile for the resulting
group.

The boundaries are intentional:

- Selecting another track inside the same group keeps the custom profile active.
- Leaving the group restores the global player settings. For example, the transition from a
  gapless-profiled album to an unprofiled track follows the global transition setting.
- A track queued independently uses global settings even if its album has a saved profile.
- A playlist-launched group uses the playlist profile; album profiles inside it do not override the
  outer group.
- Shuffling does not create a profile group because it discards the ordered sequence the profile was
  configured to protect.

Queue groups and their profile data survive playback-session restoration and history pruning.
Insertions, removals, and reordering preserve unaffected contiguous runs and avoid silently extending
a profile to unrelated music.

## Seeking and diagnostics

Waveform pointer coordinates now account for platform display density, so a selected position maps
to the same playback time across macOS displays, Android devices, and different waveform-bar counts.
Seeking has also been verified while playing, paused, and while the next gapless stream is prepared.

The BASS playback path reports the audible mixer's source position instead of a decoder position
that can run ahead during preparation. Paused near-end seeks defer next-stream preparation until
playback resumes, preventing background preparation from disturbing the selected position.

Stats for Nerds includes a Playback profile section showing whether a custom profile is active, the
queue group and target, configured overrides, resolved ReplayGain mode, and which settings will own
the next transition.

## Upgrading and compatibility

- Install `v2.2.0` over an existing `v2.1.0` installation; no reset is required.
- Shared database migration 23 adds source-scoped playback profiles and serialized queue-group state
  while preserving existing application data.
- Android, macOS, Windows, and Linux remain the supported release targets. The iOS arm64 IPA remains
  an unsigned preview for users who provide their own signing.
- Work-profile launches and group-aware Play next behavior remain planned follow-up work.
- Linux secure credentials still require Secret Service and `secret-tool`. Windows and macOS
  packages are not publisher-signed and may display operating-system warnings.
